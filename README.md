# Solana Read-Only Wallet

## Live Demo
https://solana-readonly-wallet.vercel.app

A web-based wallet dashboard that allows users to generate or import a seed phrase and derive multiple Solana wallet accounts.

---

## Features

- Generate BIP39 seed phrase
- Import existing wallet using seed phrase
- Derive multiple wallet accounts
- View SOL balance
- View SPL token balances
- Copy wallet address
- Open wallet in Solana Explorer
- Modern wallet dashboard UI

---

## Tech Stack

Frontend
- React
- Vite
- CSS

Blockchain
- @solana/web3.js
- bip39
- ed25519-hd-key
